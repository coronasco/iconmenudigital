# ICON Menu (QR landing page)

Pagină web “mobile-first” pentru meniul barului, cu căutare fixă sus la scroll și filtrare pe categorii.

## Rulare locală

Din folderul proiectului:

```bash
python3 -m http.server 5173 --directory public
```

Apoi deschide `http://localhost:5173`.

## Fișiere

- `public/index.html`: pagină meniu
- `public/styles.css`: stil minimalist + topbar sticky
- `public/app.js`: date meniu + search + filtre
